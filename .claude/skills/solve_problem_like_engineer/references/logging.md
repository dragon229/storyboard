# 實驗日誌與圖文報告格式

## 放哪裡 ⚠️

**全部放在 `research/<主題>/` 底下，不要散在專案根目錄。**

```
research/<主題>/
├── log.md              實驗日誌（單一檔案，只增不刪）
├── report_01.html      圖文報告（編號累加，不覆蓋）
├── report_02.html
└── assets/             對照圖、印樣等大檔（可選）
```

報告是 HTML 內嵌素材，動輒數 MB。跑幾輪就是好幾份，散在根目錄會把專案真正的東西淹掉。

`<主題>` 用 kebab-case，跟研究對象同名。**階段 3 開始前就把資料夾建好。**

定案的產物（腳本、設定檔）照專案原本的慣例放，**不要**塞進 `research/`——這裡只放過程紀錄。

---

## 兩種紀錄

用途不同，都要做。

| | 檔案 | 用途 | 更新時機 |
|---|---|---|---|
| **日誌** | `research/<主題>/log.md` | 累積事實與教訓，給未來的自己看 | 每輪結束就寫 |
| **報告** | `research/<主題>/report_NN.html` | 圖文對照，給人看、給人判斷 | 每個大階段結束產一份 |

---

## 日誌格式

`research/<主題>/log.md`，單一檔案，只增不刪。結構：

```markdown
# <主題> 實驗日誌

> 目標：<一句話>
> 成功判準：<可量測的 2–4 條>
> 環境：<版本、硬體、路徑>

## 量測方式
<指標定義 + 校準錨點值 + 「只能同案例內比較」這類使用限制>

## 候選盤點
<表格：候選項 / 來源 / 版本 / 大小 / 架構 / 判定>

## 實驗記錄
### R1 — <一句話變因>
| 參數 | 值 |
**數據**：<表格>
**目視**：<文字>
**結論**：<✅/❌ 條列>

### R2 — ...

## 🏁 階段結論
<能回答什麼、不能回答什麼>

## 待測 / 待辦
- [ ] ...

## 累積教訓速查
1. <教訓>（來源實驗）
2. ...
```

### 寫日誌的規則

- **邊做邊寫**，不要等最後整理。等到最後就會漏掉「當時為什麼這樣想」
- **失敗要寫**，而且要寫「為什麼失敗」，不是只寫「失敗了」
- **結論被推翻時，不要刪掉舊結論**——保留它並標註「已被 Rxx 推翻，原因是……」。未來的自己需要知道你曾經錯過，才不會再錯一次
- **教訓編號累積、永不重排**。編號是引用用的
- 每條教訓的格式：**現象 → 原因 → 對策**（附來源實驗編號）

### 教訓寫得好不好的判準

寫完問自己：**半年後只讀這一條，能不能避開同一個坑？**

```
❌ 差：參考資料要選好一點的
✅ 好：參考資料必須「不含可被誤認為目標物的元素」。污染的根因不是
      「使用參考資料」這個機制，而是參考資料裡有具體元素可被複製。
      同一套參數換成乾淨的參考資料，污染從「整組出現」變成「完全沒有」。
      （R20/R22）
```

## 報告格式

**每個子實驗一個區塊**，順序固定：

```
標題（編號 + 一句話變因）
  ↓
參數表（一列，欄位固定不變）
  ↓
成果並排：輸入 [+ 參考輸入] → 輸出
  ↓
該輪觀察（一段文字）
```

**同一組的子實驗全部列完，才給那一組的結論。** 不要在每個子實驗後面就下結論——讀的人需要先看完全部才能判斷。

### 硬性規則

- **檔名累加不覆蓋**：`report_01.html`、`report_02.html`、`report_03.html`……使用者要能前後對照。
  第一份就從 `_01` 開始編號，不要叫 `report.html`——否則第二份出現時排序會亂掉
- **素材內嵌**（如圖片用 base64），單檔可攜，不依賴外部路徑
- **每項成果下面標檔名與數據**，人工檢視時才知道在看什麼
- **參數表欄位跨區塊保持一致**，才能上下掃視比較
- 支援深色/淺色主題，寬表格自己橫向捲動

### 內容規則

- **失敗的實驗要放進報告**，而且要放成果。只放成功的等於沒有資訊量
- **「指標好但結果壞」的案例一定要單獨列出來**，這是最有價值的一種紀錄
- 結論要標明**適用範圍**：這是幾個樣本、什麼性質的樣本支持的

## 產出物的教訓內嵌

日誌與報告是給人讀的，但**改設定的人往往只看設定檔**。

所以：**把踩過的坑直接寫進設定檔的註解**，寫在會被改到的那一行旁邊。

```json
{
  "_warning": "不要換成 XX 附的那個檔案。它的內部格式不同，執行環境會靜默
               不載入且不出任何警告，結果是半成品輸出。實測差異極大。",
  "inputs": { "name": "<正確的那個>" }
}
```

判準：**別人只讀這個檔案，能不能避開你踩過的坑？**
