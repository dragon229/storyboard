# storyboard-intent｜段落意圖判讀

**輸入**：分鏡格的 `source`（＋前後各一格當上下文）
**輸出**：`rhetorical_function` / `emotional_shift` / `is_speculation`

一次閱讀得到三個結論。不要分三次讀——分開判會互相打架
（功能判成「收束」、情緒判成「初次的好奇」，自相矛盾）。

---

## 一、修辭功能（9 選 1）

**問的是：這一段對觀眾的認知做了什麼。**

| 功能 | 對觀眾做的事 | 例子 |
|---|---|---|
| **拋出鉤子** | 製造好奇，先不解釋 | 「閃電的溫度是太陽表面的五倍。」 |
| **建立前提** | 給接下來需要的已知 | 「先講一件事：空氣其實不導電。」 |
| **點出直覺** | 說出觀眾心裡本來的預設 | 「直覺上你會覺得，閃電是從天上打下來的。」 |
| **推翻** | 揭示那個預設錯在哪 | 「但你看到的那道光，其實是從地面往上竄的。」 |
| **拆解機制** | 解釋它實際怎麼運作 | 「雲底累積負電荷，地面被感應出正電荷…」 |
| **佐證** | 用例子／數據／實驗撐住主張 | 「1971 年有人用每秒兩萬張的攝影機拍下全程。」 |
| **推進** | 從已建立的往下推一步 | 「所以如果空氣要被電離才導電，那電壓就得高到某個門檻。」 |
| **敘事** | 講一段過程，讓觀眾跟著走 | 花 40 秒講富蘭克林淋著雨、鑰匙冒火花、伸手去碰 |
| **收束** | 下結論、講意涵 | 「這就是為什麼閃電是彎的——它是被摸索出來的。」 |

### 兩條必守的規則

**1. 功能由「位置」決定，不由「內容」決定。**

同一則素材，放在不同位置就是不同功能：

| 富蘭克林放風箏出現在哪 | 功能 |
|---|---|
| 開場第一句，然後切正題 | **拋出鉤子** |
| 講完電位差原理之後補一句「1752 年他證明了這件事」 | **佐證** |
| 花 40 秒講他淋雨、鑰匙冒火花、差點電死 | **敘事** |

**所以判讀一定要看上下文。只看這一段判不出來。**

**2. 功能是「論述單元」層級的屬性。**

同一個 `unit` 的所有格，填**同一個**功能值。不要因為切成三格就想把它們判成三種功能。

---

## 二、情緒偏移

頻道基調是**輕鬆好奇**（常數，寫在 `assets/style.json`）。這裡只判**相對於基調的偏離**。

**大多數格沒有偏移** → 填 `null`。不要為了填而填。

有偏移的通常是這幾個位置：

| 位置 | 典型偏移 |
|---|---|
| 拋出鉤子 | **懸念** ——「如果…」句型天生帶懸念，這格該是全片最暗、最留白、最想不通的一張 |
| 推翻 | **意外** ——「欸？」的那一瞬間 |
| 收束 | **恍然** 或 **餘韻** |
| 敘事的高潮 | 依內容（緊張、荒謬、感慨） |

情緒偏移最後會變成 prompt 尾端的一個英文片語。避免直接把情緒當主語
（✗ `sadness fills the room`），改成狀態或氛圍（✓ `a held breath before the answer`）。

---

## 三、是否為推演

**布林值。判斷這一格畫的是「確實發生過的」還是「推測的」。**

判斷依據就是修辭功能，不需要另外思考：

| 修辭功能 | `is_speculation` |
|---|---|
| 佐證、建立前提、敘事、拆解機制 | `false`（真實錨點） |
| 推進 | `true`（推演） |
| 拋出鉤子、點出直覺、推翻、收束 | **看內容**——講真實現象是 `false`，講假設世界是 `true` |

這個欄位會讓 `storyboard-compose` 套上「推演調性」，讓觀眾分辨得出真假。
判錯的後果是觀眾把推測記成事實——對科普頻道是硬傷，寧可保守標 `true`。

> **反事實影片的骨架是「錨定真實 → 推演虛構」的交替。** 「如果沒有科幻小說」之所以成立，
> 是因為能指出真實發生過的事（翻蓋手機抄 Star Trek 的通訊器）。判讀時留意這個節奏——
> 若連續十格都是 `true`，多半是漏判了中間的真實錨點。

---

## 輸出

逐格讀 `output/<系列>/<系列>.json`，填三個欄位，**立刻寫回同一個檔**，再讀下一格。
不要在記憶裡累積已完成格的內容。

跑完回報各功能的分布（例：`推進 18、佐證 9、拆解機制 7…`）。
本頻道定位是「推演的樂趣」，**推進應該是最高頻的功能**；若拆解機制遠多於推進，
多半是判讀偏了，回頭檢查。
