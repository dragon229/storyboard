# storyboard-verify-draft｜分鏡稿審稿（乙）

**輸入**：語音稿原文 ＋ `output/<系列>/<系列>.json`
**輸出**：兩份判讀有差異的格

在燒圖之前攔截**判讀錯誤**。一格判讀錯了，整格作廢；換 seed 救不回來。
這是這條流程裡價值密度最高的驗證——在最便宜的地方（純文字）攔截最貴的錯誤。

---

## 作法：遮蔽式反向獨立判讀

**必須照這個順序做，順序錯了整支 skill 就沒用了。**

### 步驟

1. **先讀原文，不要讀分鏡稿的判讀結果。**
   從 `output/<系列>/<系列>.json` 只取 `id` / `unit` / `source` 三個欄位。
   **不要看** `rhetorical_function` / `depiction_mode` / `framing`。

2. **獨立判一次。** 照 `storyboard-intent` 與 `storyboard-depiction` 的規範，
   自己判出每格的修辭功能、呈現手法、取景方向。

3. **判完之後才讀分鏡稿的原始判讀，逐格比對。**

4. **只回報差異。** 一致的格不列出。

> **為什麼順序不能顛倒**：先看到答案再判，你會不自覺地驗證那個答案，而不是獨立產生一個。
> 兩份判讀就會高度一致，報告變成一份沒有資訊量的「都符合規範」。

---

## 比對哪些欄位

| 欄位 | 差異代表 | 嚴重度 |
|---|---|---|
| `rhetorical_function` | 讀錯了這段在論述裡幹嘛。**會連鎖污染下游全部決策** | 高 |
| `is_speculation` | 真假標錯。觀眾會把推測記成事實 | 高 |
| `depiction_mode` | 手法選得可能不好。但這是選擇題，多解並存——差異不等於錯 | 中 |
| `framing` | 取景不同。同樣是選擇題 | 低 |
| `emotional_shift` | 情緒判讀不同 | 低 |

**修辭功能的差異最值得看**，因為它是唯一有標準答案的欄位。手法與取景的差異只是「另一種也可以」，
除非撞到硬約束（見下）。

---

## 額外檢查的硬約束

這些不是「兩份判讀不一樣」，是**明確違規**，一律回報：

| # | 檢查 |
|---|---|
| H1 | 手法有沒有落在傾向表的「**避免**」欄？（鉤子用示意圖、拆解機制用實景、佐證用隱喻、敘事用示意圖） |
| H2 | 同一手法有沒有連續超過 2 格？ |
| H3 | 主持角色有沒有超過 10 格沒出現？ |
| H4 | 「點出直覺 → 推翻」這一組，兩格的取景有沒有構成對照（同景別、同視角、同構圖）？ |
| H5 | 同一個 `unit` 的多格，`rhetorical_function` 有沒有填成不一樣的值？（功能是單元層級屬性） |
| H6 | 連續超過 10 格都是 `is_speculation: true`？多半漏判了中間的真實錨點 |
| H7 | 全片的功能分布裡，「推進」是不是最高頻？不是的話多半判讀偏了（本頻道定位是推演） |

---

## 輸出

```
【判讀差異】
  s07  功能：分鏡稿「佐證」→ 獨立判讀「推進」
       原文講的是推測後果，不是既有事實
  s19  推演：分鏡稿 false → 獨立判讀 true

【硬約束違規】
  s03  H1 手法違規：功能是「拋出鉤子」但選了示意圖（傾向表列為避免）
  s31  H4 對照失效：s30 點出直覺用中景平視，s31 推翻用特寫俯角，兩格對不上
```

**不要自動修改分鏡稿。** 只報告，讓使用者決定。
