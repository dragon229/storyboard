# 語音稿 → 場景清單 切分規範（階段一）

本檔是五階段流程的**階段一**規範：把一整篇語音稿，切成一格一格的分鏡場景清單。

```
A（語音稿全文） + B（本檔） + C（LLM） = D（場景清單）
```

輸出的每個場景，會成為**階段二**（`語音稿轉提示詞規範.md`）的輸入。所以本階段的任務是：**決定切幾格、每格涵蓋哪段原文、每格的視覺主軸是什麼**——但**不寫英文提示詞**（那是階段二的事）。

---

## 輸出格式

場景清單是一個 JSON 陣列，每個場景包含：

```json
{
  "id": "s01",
  "scene": "Day 3｜命令紙送到連部",
  "dialogue": "第二營第三連，即刻前往第六軍區駐地報到，隨時待命，應對突發公衛事件。",
  "source": "那天下午三點，命令送到連部。一張紙。上面寫著：……",
  "focus_hint": "物件焦點：一張命令紙的特寫，紙上有印刷字與紅色關防",
  "location": "軍事連部室內"
}
```

| 欄位 | 內容 | 給誰用 |
|------|------|--------|
| `id` | 場景編號 `sNN`，依序 | 全流程 |
| `scene` | 中文短標題，格式 `時間段｜地點/事件`。**若視覺主軸是某角色，標題要含該角色中文名或稱謂**（周下士、林少校…），這樣階段三 keyword 才會觸發造型疊加。 | 階段二、三 |
| `dialogue` | 這一格對應的關鍵台詞（通常是原文裡最能代表這個畫面的一句） | 階段二、三 |
| `source` | 這一格涵蓋的原文段落（可整段），供階段二理解上下文 | 階段二 |
| `focus_hint` | 這一格的視覺主軸提示：焦點類型 + 一句話說明要讓觀眾看到什麼 | 階段二 |
| `location` | 這一格的場景地點（中文簡述）：原文有明確描述就直接取；**沒有明確描述時必須從前後文推斷**，不可留空。 | 階段二 |

> `source`、`focus_hint`、`location` 是階段一額外提供給階段二的線索，讓階段二不必再回頭讀整篇語音稿就能寫出正確的 prompt——特別是 `location` 可防止生圖模型因缺乏地點資訊而自行把室內場景畫成戶外。

---

## 切分原則：什麼時候切一格新場景

一段敘事文字，遇到下列任一情況就切一格新場景：

1. **地點改變**：連部 → 停車場 → 餐廳，各是一格。
2. **時間跳躍**：「那天下午」→「天黑了」→「第二天」，各是一格。
3. **視覺焦點轉移**：同一段裡先講命令紙、再講老張的反應，是兩個不同的畫面 → 兩格。
4. **情緒轉折**：平靜的日常突然被一個壞消息打斷，轉折點切一格。

反過來，**不要**因為以下原因切格：
- 純對話來回但畫面沒變（同一個畫面可涵蓋數句對白，選最代表性的一句放 `dialogue`）。
- 敘述者的內心補充說明（併入它所依附的那個畫面）。

---

## 選視覺主軸：一段文字有多件事時畫哪一件

每一格只有**一個視覺主軸**。當涵蓋的原文段落裡有多件事，問：

1. **這一刻最該讓觀眾「看到」的是什麼？** 不是「聽到」什麼，是「看到」什麼。
2. **哪個畫面最能推進故事或承載情緒？**
3. 選定後，用 `focus_hint` 記下**焦點類型**（見下表八種之一）＋一句話。

> 範例：原文「命令送到連部。一張紙。上面寫著：第二營第三連即刻前往……老張站在旁邊說，公衛事件，哪一種公衛事件需要整個連去待命？」
> - 最該看到的是**那張命令紙的內容**（故事的起點、資訊的載體）。
> - 老張的疑問是「聽到」的，不是這一格的視覺主軸 → 可以另切一格（老張的反應），或本格不畫。
> - `focus_hint`：`物件焦點：命令紙特寫，紙上印刷字＋紅色關防，桌面平放`

## 地點推斷規則：`location` 欄位不可留空

每個場景都必須填 `location`。原文有明確指出地點就直接用；**沒有明確指出時，依下列步驟推斷**：

### 推斷步驟

1. **向前查找**：找最近一個有明確地點的場景，確認人物是否還在同一個地方（中間沒有描述移動）。
2. **向後確認**：看這個場景之後有沒有「人物離開／移動到別處」的描述——有才切換地點，沒有就沿用。
3. **沿用直到有明確切換**：人物沒移動就假設還在同一個地點。

### 地點的寫法

用中文簡述，**點出室內/室外 + 場所類型**，一行內寫完：

| 場景情境 | `location` 寫法範例 |
|---------|------------------|
| 軍事基地連部辦公室 | `軍事連部室內` |
| 軍事基地走廊、樓梯間 | `軍事基地走廊` |
| 軍事基地餐廳 | `軍事餐廳室內` |
| 軍事基地戶外停車場 | `軍事基地戶外停車場` |
| 軍事基地簡報室 | `軍事簡報室室內` |
| 廢棄城市街道（戶外） | `廢棄市區街道（戶外）` |
| 公寓樓梯間 | `公寓樓梯間（室內）` |
| 電廠廠房 | `電廠廠房室內` |
| 電廠控制室 | `電廠控制室室內` |
| 醫療區 | `醫療區室內` |
| 郊野公路 | `郊野公路（戶外）` |

> **室內/室外一定要寫清楚**：生圖模型若沒有明確的室內/室外訊號，極容易把場景畫錯。即使是「走廊」這種看起來明確的地點，也請加「室內」確認。

## 焦點判準：焦點是「推進故事的那件事」

選視覺主軸時，**最高判準是「這一格真正推進故事、或承載這個 beat 情緒重量的那件事」**——不是最好畫的、最具體的，也不是台詞這句話的文字剛好寫在哪個物件上的那一個。

### 判準一：焦點是「當下推進故事的事件」，不是承載它的靜物

一個物件（筆記本、名單、地圖、螢幕、紙張）出現在段落裡，它可能只是**故事的靜態載體**，也可能是**當下事件的現場**。判準是問一句：**這一格有沒有一個「正在發生、把故事往前推」的行為？** 有的話，焦點是那個行為／事件，不是承載它的物件。

**穿透兩層——把焦點從靜物移到它背後的事件與現實：**

1. **穿透「記錄動作」**：「記下來／寫進名單／登記」是記帳（bookkeeping），是把**已發生**的事收尾存檔，本身不推進故事。要穿透它，去看**被記錄的那個事件**。
2. **穿透「抽象符號」**：記錄的內容若是數字、清單這類抽象符號，即使它承載危機或情緒（資源見底、傷亡累積），也要穿透到它**指涉的具體現實**，用實體來承載重量，而不是停在符號上。

| 原文（要有足夠上下文才判得出焦點） | ❌ 停在靜物／符號 | ✅ 穿透到事件／現實 |
|------|------------------|--------------------|
| 「清掃完，我們在路口集合，二排往前掃過一遍巷弄，回報乾淨。我繞著倒下的目標走了一圈，數清楚，然後翻開筆記本記下。十七個目標，二十三發子彈。」 | 物件焦點：筆記本上的數字 | 環境／動作焦點：清掃後路口、繞行清點滿地放倒目標的現場（「十七個目標」＝滿地放倒的實體） |
| 「筆記本第一頁我寫下：死人在電梯裡動了。」 | 物件焦點：筆記本上那行字 | 動作焦點：電梯裡的屍體動起來——那個「動」才是畫面 |

> **兩個提醒**：（1）判斷焦點型別要看**足夠的原文上下文**——上表左欄是完整段落；光憑「翻筆記本記下數字」這種抽掉頭尾的殘句，判不出該畫什麼。（2）穿透記錄後**再問一次「值不值得一格」**：若被記錄的事件本身份量不足（零星的例行登記），這一格可能根本不需要獨立成畫面，可併入相鄰場景，別為了「有東西可畫」硬切一格。

**反過來——物件本身就是焦點的三種情況**（此時不穿透，直接畫物件）：

| 情況（通則） | 為什麼焦點在物件 | 場景例 |
|-------------|-----------------|--------|
| **有主體正在「讀取／發現」它** | 「讀到／發現」是當下正在發生、推進故事的事件，記錄物件是這事件的核心；與「當初寫下」相反（寫是過去，讀是當下） | 女孩在廢墟裡撿到並翻開陌生人的筆記本 |
| **它指向「未來的行動」** | 計畫／地圖標記／待執行的命令是**前瞻**的，預告接下來要發生什麼——與「記帳過去」方向相反，本身在推進故事 | 地圖上標出下一步路線、命令紙下達新任務 |
| **它是「剛送達的新資訊」** | 資訊的「到達」本身是事件，內容是劇情的新輸入 | 命令送到連部、電視播疫情升級、機密文件被打開 |

> **一句話收束**：**過去的、被動的記錄 → 穿透看事件與現實；當下的讀取、未來的計畫、新到的資訊 → 物件本身就是事件。**

### 判準二：冗餘檢查

`focus_hint` 如果只是把 `dialogue` 這句話「渲染成看得見的字」（畫面＝台詞的圖示），畫面就沒補充任何台詞沒說的東西 → 幾乎都是選錯了。**畫面該給的是台詞背後的代價／現場／後果**，而不是重複台詞本身。（此條針對「被寫下的文字」；若 `dialogue` 是角色**說出口**的話，用人物焦點讀臉並不算冗餘。）

## 焦點類型（索引，完整定義見階段二）

`focus_hint` 只需要標出「類型 + 一句話」，**不需要決定鏡頭或構圖**——鏡頭遠近、局部/全身取景、構圖手法都是階段二的事（依賴更多上下文才能判斷，例如動作是全身參與還是單一局部身體部位）。完整定義、鏡頭規則、範例請見 `語音稿轉提示詞規範.md`「焦點類型與鏡頭」章節，本檔只列類型名稱與敘事目的供選型：

| 類型 | 用於（敘事目的） |
|------|-----------------|
| **物件焦點** | 物品的特徵、質感、或對劇情的重要性 |
| **人物焦點** | 角色的情緒、心理狀態、或台詞表達 |
| **動作焦點** | 一個關鍵動作、動態軌跡、或爆發的瞬間 |
| **環境焦點** | 故事背景、世界觀、規模、或空間氛圍 |
| **關係焦點** | 兩個或多個主體間的相對位置、階級、或心理拉鋸 |
| **對比焦點** | 反差突顯孤立感、內心矛盾、或戲劇張力 |
| **細節/提示焦點** | 放大局部，提示關鍵線索或倒數危機 |

> **選型提示**：多數場景會落在物件/人物/動作/環境四種基本類型。當一格的重點明顯是「兩人之間的張力」而非單一主體，選**關係焦點**；重點是「反差本身」而非某個具體物件/人物，選**對比焦點**；重點是「一個極小的線索」，選**細節/提示焦點**。
>
> **不設「轉移焦點」**：單張靜態圖無法呈現「焦點隨時間轉移」的過程（那是影片/連續鏡頭的手法）。前景/背景清晰度對比等構圖技巧仍可用，但附加在上述類型上，不獨立成一格的焦點類型。

## 與下游階段的銜接

- 階段二讀 `source` + `focus_hint` + 本場景的 `scene`/`dialogue`，寫出 `pre_prompt`。
- 階段三用 `scene` + `dialogue` 的中文關鍵字觸發 `分鏡稿規範.json` 的疊加。
- 因此**階段一務必把角色稱謂正確寫進 `scene`**（例如「周下士」而非「一個士兵」），否則階段三疊不到造型。
